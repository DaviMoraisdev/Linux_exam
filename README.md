# Linux Essentials — Simulado D281 em português

[▶ Iniciar o simulado de Linux Essentials](https://davimoraisdev.github.io/Linux_exam/linux-essentials-d281-pt-br.html)

Estude fundamentos de Linux com 80 questões de múltipla escolha em português do Brasil. Cada questão traz um gabarito comentado que explica a resposta. Os comandos, caminhos e exemplos de saída mantêm a grafia original para que você possa reconhecê-los no terminal.

## Como começar

Baixe o arquivo `linux-essentials-d281-pt-br.html` e abra-o com dois cliques no navegador. Se a versão publicada no repositório se chamar `index.html`, abra esse arquivo. O simulado funciona offline após o download. Todo o conteúdo, os estilos e o JavaScript estão no próprio HTML.

| Modo | Como usar |
| --- | --- |
| **Praticar** | Resolva as questões na ordem do material. Depois de responder, clique em **Ver gabarito** para conferir as alternativas corretas e ler a explicação. |
| **Fazer simulado** | Responda às 80 questões em ordem aleatória. Use **Marcar para revisar** nas que gerarem dúvida e **Navegar pelas questões** para voltar a elas. Na última questão, clique em **Entregar simulado** para ver sua nota e revisar as respostas. |

Nas questões com mais de uma resposta, o enunciado indica quantas alternativas selecionar. Para acertar, marque o conjunto completo de alternativas corretas. A tela inicial dá acesso ao **Histórico de simulados**, que guarda os resultados no próprio navegador.

## O que você vai praticar

- **Terminal e arquivos** — navegar por caminhos relativos, buscar arquivos com `find`, filtrar linhas com `grep` e criar arquivos compactados com `tar`.
- **Shell script** — interpretar laços `for`, usar variáveis de ambiente e entender o código de saída de um comando.
- **Usuários e permissões** — interpretar `rwx` e permissões octais, alterar o dono de um arquivo e consultar contas e grupos.
- **Processos, memória e hardware** — identificar PIDs, interpretar a saída de `free` e `top` e reconhecer dispositivos em `/dev`.
- **Redes e distribuições** — distinguir registros DNS, identificar a função do DHCP e reconhecer distribuições, gerenciadores de pacotes e licenças de software livre.

## Publicação no GitHub Pages

Siga estes passos para usar o simulado como página inicial de um repositório dedicado a ele.

1. Salve o HTML como `index.html` na raiz do repositório, ao lado deste `README.md`, e faça o commit.
2. No GitHub, abra **Settings → Pages**. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch que contém o HTML (por exemplo, `main`), selecione a pasta **/(root)** e clique em **Save**.
4. Quando a publicação terminar, abra **Visit site** na mesma tela para acessar o simulado e copiar o endereço.

[Documentação do GitHub Pages](https://docs.github.com/pt/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
