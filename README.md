Caderno de estudo em português do Brasil para praticar comandos, interpretar saídas do terminal e revisar os fundamentos de Linux.

| Aba | Conteúdo |

## Como estudar

1. Abra a aba **Quizlet** e filtre por conjunto ou assunto. Para praticar as 77 questões adicionais, marque **Só questões fora do banco D281**.
2. Nos cartões, use **Ver gabarito** para conferir a explicação e **Marcar para revisar** para guardar uma questão para depois.
3. Para testar o que aprendeu, escolha a quantidade e clique em **Iniciar simulado**. As questões são sorteadas sem repetição.
4. Ao entregar, as questões de alternativas são corrigidas automaticamente. Nas abertas, compare o que escreveu com a resposta de referência e indique se acertou. No fim, confira a nota e revise suas respostas.

## Uso offline

Baixe o arquivo `linux-essentials-d281-pt-br.html` e abra-o no navegador. As questões, os estilos e o JavaScript estão no próprio arquivo.
