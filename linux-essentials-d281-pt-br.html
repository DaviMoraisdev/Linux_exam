Questão 80 de 80

Qual afirmação sobre links em sistemas de arquivos Linux está correta?

Selecione uma alternativa.
Ver gabarito
Gabarito · E

Um link simbólico guarda um caminho. Ele pode apontar para arquivos ou diretórios, inclusive em outro sistema de arquivos. Um link físico referencia o mesmo inode e precisa permanecer no mesmo sistema de arquivos. Se o caminho guardado por um link simbólico deixar de existir, o link deixa de resolver o destino.
